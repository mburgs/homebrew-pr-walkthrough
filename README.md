# homebrew-pr-walkthrough

Homebrew tap — the **public distribution channel** for
[`pr-walkthrough`](https://github.com/mburgs/pr-walkthrough), a guided,
browser-based review of a GitHub pull request. The source repo is
private; this repo holds only the generated formula and its release
assets.

## Install

```bash
brew install mburgs/pr-walkthrough/pr-walkthrough
export ANTHROPIC_API_KEY=sk-ant-...   # and have `gh` authed
pr-walkthrough owner/repo/pull/N
```

Homebrew pours a prebuilt bottle and brings in what it needs — Python,
Node, ripgrep, and a pinned TypeScript language server for references in
TypeScript repos. `pr-walkthrough setup` (optional) adds pyright for
Python references and turns on execution exhibits.

## Update

```bash
brew upgrade pr-walkthrough    # or: pr-walkthrough upgrade
```

## Requirements

macOS on Apple Silicon (arm64). CI builds one bottle, `arm64_sonoma`,
which Homebrew also pours on newer macOS. Installing from source instead
of the bottle trips Homebrew's dylib relocation on code-signed Rust
wheels, so other platforms aren't supported yet.

## How this works — do not hand-edit the formula

`Formula/pr-walkthrough.rb` is **generated by CI** in the source repo
when a version tag (`v*`) is pushed there. Each release here carries the
wheel and the bottle the formula points at. Manual edits to the formula
are overwritten on the next publish. Versions are UTC timestamps
(`YYYY.MM.DD.HHMMSS`), so `brew upgrade` always sorts the newest highest.
